# Отпечаток SHA-256 сертификата боевого ключа подписи Android — контрольная
# точка смены ключа (.ultraplan/research/04-android-release.md §5, §7;
# apps/mobile/scripts/android-release-gate.mjs → expectedSignerGate).
#
# ── Пока строка ниже пуста ───────────────────────────────────────────────
#
# Ключ ещё не создан. Это ОЖИДАЕМОЕ состояние на старте продукта, а не
# авария: производственная сборка (тег shagi-v*, пуш в ветку по умолчанию,
# ручной запуск с явным выбором production) намеренно падает на шаге
# подготовки keystore с сообщением «ключ подписи ещё не создан, выполните
# scripts/make-android-keystore.sh». Разработческие сборки (pull request,
# чужая ветка, ручной запуск без выбора канала) этот файл вообще не читают
# — они собирают debug-APK постоянным отладочным ключом из
# apps/mobile/keys/, объяснение — apps/mobile/keys/README.md.
#
# ── Как заполнить (один раз, после scripts/make-android-keystore.sh) ──────
#
#   1. Скопируйте строку «SHA256:» из вывода скрипта — шестнадцатеричные
#      пары через двоеточие или без них, регистр не важен, скрипт
#      приводит их к одному виду сам.
#   2. Впишите её единственной незакомментированной строкой ниже.
#   3. Закоммитьте вместе с заведёнными секретами репозитория:
#      ANDROID_KEYSTORE_BASE64, ANDROID_KEYSTORE_PASSWORD,
#      ANDROID_KEY_ALIAS, ANDROID_KEY_PASSWORD.
#
# ── После первого заполнения ───────────────────────────────────────────────
#
# Строка ниже становится точкой отсчёта: production-сборка сверяет с ней
# отпечаток, реально извлечённый из keystore в секретах. Расхождение —
# ВСЕГДА отказ сборки, а не предупреждение: смена ключа подписи должна быть
# громкой. У Записок та же сверка защищает App Links (assetlinks.json); у
# ШАГОВ в R1 App Links нет вовсе — нет аккаунта, нет входа по ссылке из
# письма. Но подпись остаётся личностью приложения независимо от этого:
# Android ставит обновление поверх установленного только если подпись
# совпала, и молча принять здесь другой ключ значило бы молча испортить
# обновление всем, кто уже поставил ШАГИ, — самая дорогая ошибка, которую
# можно допустить тихо. Поэтому расхождение видно СРАЗУ, на этом шаге.
