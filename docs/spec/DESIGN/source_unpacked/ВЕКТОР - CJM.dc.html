Customer Journey Map: голосовой сброс мыслей на ходу

Персона: пользователь ШАГОВ, ведёт машину, руки и внимание заняты. В голове три несвязанных дела и одна идея. Пайплайн: Input → Intent → Entity extraction → Router → Target app/action. Confidence model решает, что происходит дальше без лишних касаний.

Этап 1
Триггер
За рулём, руки заняты
Действие
Вспоминает три дела и одну идею сразу. Тянуться к экрану и печатать — не вариант.
Мысль
«Если не скажу сейчас — забуду половину до вечера».
Точка контакта
Голосовой shortcut / виджет на экране блокировки / часы (future integration surface, §11).
Возможность
Захват без разрыва текущего действия — руки и глаза остаются на дороге.
Этап 2
Захват (Input)
Слушаю…
«…купить корм коту, ещё отправить Ивану презентацию до пятницы, и вообще — идея для курса про фокус»
Действие
Говорит потоком, без пауз и без попытки заранее структурировать мысль — как в Ramble.
Мысль
Видит live partial transcript — можно говорить быстрее, ошибка не страшна, всё редактируется потом.
Точка контакта
Streaming partial transcript на экране/часах; ASR — GigaAM, локально где возможно (§55, не брендируется в UI).
Риск
Шум в машине, лаг в транскрипте — если отставание видно, доверие к записи падает уже на этом шаге.
Этап 3
Разбор (Intent → Entity → Router)
1 фраза → 3 интента
2 → ШАГИ, 1 → ЗАПИСКИ
Действие
Ничего не делает — пайплайн сам режет поток на сущности и маршрутизирует по приложениям-получателям.
Мысль
Пауза без обратной связи тревожит — нужен короткий тактильный/звуковой отклик, а не тишина.
Точка контакта
Фоновая обработка; исходное аудио не хранится после успешного распознавания (privacy-by-default, §55).
Риск
Ошибка распознавания не должна вести к скрытому долгому хранению записи «на всякий случай».
Этап 4
Confidence model — развилка
Каждый из 3 извлечённых интентов проходит развилку independently — не вся фраза целиком.
High → выполнить сразу + Undo · Medium → короткий preview на подтверждение · Low → один уточняющий вопрос, не больше (§55).
High confidence
«Купить корм коту»
Добавлено в Входящие Отменить
Выполняется без подтверждения — быстро + Undo (V04).
Medium confidence
«Отправить Ивану презентацию до пятницы»
До пятницы, 5 сент? Иван П. — 2 контакта с этим именем
ВерноИсправить
Preview перед сохранением — можно исправить target/дату/объект (V05).
Low confidence
«…идея для курса про фокус»
Это заметка или задача?
ЗаметкаЗадача
Только один необходимый вопрос — не форма (V06).
Этап 5
Результат в целевом продукте
Связано
🎙 Голосовой ввод · 09:14
Действие
Позже открывает ШАГИ и ЗАПИСКИ — видит готовые объекты, а не сырую запись для расшифровки.
Мысль
«Всё три дела на месте, и понятно, что каждое пришло из одной и той же фразы».
Точка контакта
Task Detail / заметка показывают источник — «ясно, что объект создан через ВЕКТОР» (V07).
Возможность
Одна фраза → несколько продуктов СИМПАС наполняются одновременно, без переключения между ними.
Этап 6
Доверие и повтор
Метрика: доля задач через голос растёт (§86)
Действие
Продолжает вести машину — не отвлекается на проверку, потому что ошибки были пойманы на шаге confidence.
Мысль
«В следующий раз просто наговорю всё сразу, не буду открывать приложения».
Точка контакта
Settings → Данные и конфиденциальность → управление голосовыми данными (future, §43.2).
Возможность
Голос становится основным способом захвата для мультизадачных ситуаций — NLP-текст остаётся для тихих моментов.
