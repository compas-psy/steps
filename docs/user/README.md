# Пользовательская документация

Каталог заведён пакетом работ E00.1 (каркас монорепозитория) как часть
структуры `docs/` из SPEC/00 §13: «user-visible change updates
`docs/user/` and changelog in same PR».

Содержимое появляется вместе с первым пользовательским эпиком (E04+) —
любое изменение, видимое пользователю, обновляет этот каталог и changelog
в том же PR, где меняется поведение.
