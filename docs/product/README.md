# Продуктовая документация

Каталог заведён пакетом работ E00.1 (каркас монорепозитория) как часть
структуры `docs/` из SPEC/00 §13. Содержимое появляется по мере
реализации продуктовых эпиков (E04+): описания фич поверх нормативного
источника `docs/spec/SOURCE/` — Product/UX Spec v4.0.

Нормативный продуктовый источник — `docs/spec/SOURCE/`, он заморожен и не
редактируется. Здесь — производные материалы: решения, которые не
дублируют SPEC, а поясняют его для команды.
