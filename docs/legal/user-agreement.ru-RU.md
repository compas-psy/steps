# Пользовательское соглашение ШАГОВ

Соглашение описывает условия использования приложения ШАГИ версии
`MVP 1.0-local`. Устанавливая и используя приложение, вы принимаете эти
условия. Если вы с ними не согласны — не используйте приложение.

## Что это за программа

ШАГИ — персональный планировщик задач. Приложение помогает записывать
задачи, планировать их по датам и времени, разбивать на подзадачи и
чек-листы и напоминать о них.

## Локальный характер этой версии

В версии `MVP 1.0-local` нет учётной записи, входа и синхронизации.
Приложение работает целиком на вашем устройстве и хранит данные только на
нём.

Из этого следует главное, что вам нужно знать: **ваши данные существуют
ровно в одном экземпляре — на вашем устройстве.** Разработчик не хранит их
копию и не может восстановить их для вас.

## Резервные копии — ваша ответственность

Разработчик не делает резервных копий ваших данных и не гарантирует
восстановление в случае:

- потери, поломки, кражи или замены устройства;
- удаления приложения;
- сброса устройства к заводским настройкам;
- очистки данных приложения средствами системы;
- использования действия «Удалить локальные данные» в самом приложении;
- очистки данных сайта в браузере — для веб-версии.

В приложении есть экспорт: он создаёт файл резервной копии, который
сохраняете и храните вы. Регулярный экспорт — единственный способ не
потерять данные в этой версии.

## Отсутствие облачного восстановления

Никакого облачного хранилища, серверной копии и восстановления по учётной
записи в этой версии не существует. Ни один экран приложения не обещает
такой возможности, и её не появится, пока не выйдет версия, где
синхронизация заявлена явно и описана в обновлённых документах.
