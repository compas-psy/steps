# ШАГИ — правила работы в репозитории

Personal task manager, экосистема СИМПАС. Local-first, offline-first, `ru-RU`.

## Ловушка окружения — прочитать первым

В контейнере `/opt/node22/bin` стоит в `PATH` раньше `/usr/local/bin`, куда
слинкован нужный Node 24.20.0. **Голый `node --version` лжёт.** Любая команда
начинается с:

```
export PATH=/usr/local/bin:$PATH
```

Проверка: `node --version` обязан дать `v24.20.0`. Версии зафиксированы
точками, а не диапазонами — ADR-0001.

## Источник истины

`docs/spec/` — замороженный контракт, **редактированию не подлежит**.
Целостность проверяется `sha256sum -c docs/spec/SHA256SUMS.txt` (40/40).

Приоритет при расхождении источников: `01_PRODUCT_BEHAVIOR_R1` →
`02_DATA_MODEL_SYNC` → `03_BACKEND_API` → `04_UI_DESIGN_SYSTEM` →
`00_MASTER_IMPLEMENTATION_TZ` → `05_SECURITY_PRIVACY_LEGAL` →
`07_RELEASES_FUTURE` → `SOURCE/PRODUCT_SPEC_v4.0` → `DESIGN/`.

HTML-прототип в `DESIGN/` задаёт визуальный результат, а не архитектуру.
Витринный хром — темы «Бумага/Графит/Чернила», рамки устройств, фейковые
статус-бары — в продукт не переносится.

Готовые конспекты разведки: `.ultraplan/research/` (домен, UI, качество,
релизный контур Android). Принятые решения по недосказанностям ТЗ:
`.ultraplan/open-questions.md` — они **утверждены владельцем**, не
пересматривать.

## Границы пакетов

```
apps/{web,desktop,mobile}   только оболочки
packages/core               домен: сущности, команды, инварианты, время, ранги
packages/storage            репозитории, адаптеры SQLite и IndexedDB
packages/nlp                детерминированный русский парсер
packages/ui                 токены и компоненты, без продуктовых строк
packages/app                ВСЕ экраны, маршруты, поведение
packages/i18n               каталоги строк
packages/platform           интерфейсы возможностей платформы
```

**Инвариант ТЗ §3:** ни одного экрана, бизнес-правила, правила NLP или sync,
ни одной пользовательской строки в `apps/*`. Проверяется автоматически
(`apps/web/test/architecture-boundary.test.ts`) — и по прямым импортам домена,
и по кириллице в JSX.

Публичный API пакета — только `./src/index.ts`. Глубокие импорты запрещены.

## Гейты, которые нельзя ослаблять

Все они уже ловят настоящие нарушения — это проверено внесением нарушений,
а не предположением. Если гейт мешает — чини код, а не гейт.

| Гейт                          | Что ловит                                                                |
| ----------------------------- | ------------------------------------------------------------------------ |
| адгезия дизайн-системы        | сырые hex, сырые px, чужие `font-family` вне слоя токенов                |
| `check-i18n-catalog.mjs`      | ключ использован, но отсутствует в каталоге `ru-RU`                      |
| `check-signing-secrets.mjs`   | исключения для ключей подписи в `.gitignore`, ключи под контролем версий |
| `check-log-hygiene.mjs`       | прямые `console.*` вне фасада логгера                                    |
| `check-license-allowlist.mjs` | лицензии вне списка разрешённых                                          |
| граница `apps/*`              | импорт домена и пользовательские строки в оболочках                      |
| контраст WCAG AA              | пары «текст на фоне» ниже 4.5                                            |

## Что закладывается в домен с первого дня

Иначе бэкенд-волна потребует переписывания:

1. Единая точка входа `CreateTaskCommand` — через неё идут Quick Add, импорт
   и все будущие адаптеры. Прямая запись в хранилище запрещена.
2. Один валидатор на все инварианты — общий для локальных команд и входящих
   sync-патчей.
3. Детерминированный UUIDv5 для occurrence повторов, не UUIDv7.
4. Outbox пишется в одной транзакции с сущностью.
5. Per-field HLC и `revision` на изменяемых сущностях.
6. Tombstone вместо жёсткого удаления, retention 90 дней.
7. `capture_state`, `source`, снимок имени проекта на Task.

## Время

Нативный `Date` в доменной логике **запрещён** (ТЗ §5). Только
`@js-temporal/polyfill`: `PlainDate` для дат, `PlainTime|null` для времени,
целые минуты для длительности, `Instant` для системных меток.

Смысл: после смены пояса задача на 09:00 остаётся на 09:00 по местному.
Пересчитывается только расписание уведомлений, но не сами даты задач.

## Локализация

Все пользовательские строки — через `packages/i18n`. Переиспользуемые
компоненты не содержат продуктового текста. Отсутствующий ключ `ru-RU` в
production-сборке роняет CI. Тон копирайтинга — взрослый и спокойный, без
инфантилизации и геймификации (ТЗ §18).

## ADR

Любое отклонение от стека или архитектуры ТЗ фиксируется ADR в `docs/adr/`,
**в том же изменении, что и реализация**. Имя файла — латиницей,
транслитерацией (macOS нормализует имена в NFD, git в NFC, кириллица начинает
двоиться между раннерами); заголовок и текст внутри — по-русски.

## Проверка перед сдачей

```
export PATH=/usr/local/bin:$PATH
pnpm install --frozen-lockfile
pnpm -r typecheck && pnpm -r lint && pnpm -r test
pnpm --filter @shagi/web build
pnpm format:check
```

**Не заявляй, что проверка прошла, если ты её не запускал.** Отчёт содержит
дословный вывод команд, а не пересказ. Если тест что-то гарантирует —
убедись, что он краснеет при нарушении: проверка, которая не может упасть,
хуже отсутствующей, потому что создаёт ложную уверенность.

## Стиль

Комментарии и документация по-русски. Комментарий объясняет **почему** так
сделано, а не пересказывает код. Ссылка на раздел ТЗ или на разбор реальной
поломки ценнее описания.

Ориентир по конвенциям — соседний продукт `compas-psy/zapiski`: тот же стек,
та же организация. Расходиться с ним без причины не нужно.

## Ключ подписи Android

Создаётся владельцем вручную, один раз на всю жизнь продукта, скриптом
`scripts/make-android-keystore.sh`. В репозитории не появляется никогда —
только публичный отпечаток в `apps/mobile/EXPECTED_SIGNER.txt`. Сборка без
полного комплекта секретов падает на любом канале: половина настройки — это
ошибка, а не повод собрать что-нибудь. Разбор схемы —
`.ultraplan/research/04-android-release.md`.
